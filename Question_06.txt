QUESTION 6

Implement an RNN model for sequential data processing.

AIM
To implement the given task using Python and obtain the required output.

ALGORITHM
1. Start the program.
2. Import NumPy and TensorFlow libraries.
3. Generate sequential sample data.
4. Create input sequences using a fixed-size sliding window.
5. Split the sequences into training and testing sets.
6. Construct an RNN model with a SimpleRNN layer and output layer.
7. Compile and train the model.
8. Evaluate the model and predict the next sequence value.
9. Display the error and predicted value.
10. Stop the program.

PROGRAM

import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import LSTM, Dense, Dropout

# Generate sample video data
# 100 videos, 10 frames, 64 features
X = np.random.rand(100, 10, 64)

# Generate video labels (3 classes)
y = np.random.randint(0, 3, 100)

# Build LSTM model
model = Sequential([
    LSTM(128, input_shape=(10, 64)),
    Dropout(0.3),
    Dense(64, activation='relu'),
    Dense(3, activation='softmax')
])

# Compile the model
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# Train the model
model.fit(X, y, epochs=10, batch_size=16)

# Evaluate the model
loss, accuracy = model.evaluate(X, y)

print("Test Accuracy:", accuracy)

# Predict video class
prediction = model.predict(X[:1])
print("Predicted Class:", np.argmax(prediction))
