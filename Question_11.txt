QUESTION 11

Develop a CNN model to classify images into different categories.

AIM
To implement the given task using Python and obtain the required output.

ALGORITHM
1. Start the program.
2. Import TensorFlow and the required Keras layers.
3. Load the CIFAR-10 image dataset.
4. Normalize the training and testing images.
5. Construct a CNN using convolution, pooling, flatten and dense layers.
6. Compile the CNN with Adam optimizer and classification loss.
7. Train the model using the training images.
8. Evaluate the model using the test images.
9. Display the test accuracy.
10. Stop the program.

PROGRAM
import tensorflow as tf
from tensorflow.keras import layers, models

# Load dataset
train = tf.keras.utils.image_dataset_from_directory(
    'dataset',
    validation_split=0.2,
    subset='training',
    seed=123,
    image_size=(64, 64),
    batch_size=32
)

test = tf.keras.utils.image_dataset_from_directory(
    'dataset',
    validation_split=0.2,
    subset='validation',
    seed=123,
    image_size=(64, 64),
    batch_size=32
)

# Build CNN model
model = models.Sequential([
    layers.Rescaling(1./255, input_shape=(64, 64, 3)),
    layers.Conv2D(32, (3, 3), activation='relu'),
    layers.MaxPooling2D(2, 2),

    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D(2, 2),

    layers.Flatten(),
    layers.Dense(128, activation='relu'),
    layers.Dense(len(train.class_names), activation='softmax')
])

# Compile model
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# Train model
model.fit(train, epochs=5, validation_data=test)

# Evaluate model
loss, accuracy = model.evaluate(test)

print("Test Accuracy:", accuracy)
print("Image Categories:", train.class_names)

OUTPUT
Expected output:
The program displays training progress and the final test accuracy.

RESULT
Thus, the given task was implemented successfully using Python.
