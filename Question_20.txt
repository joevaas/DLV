QUESTION 20

Implement an RNN model for sequential data processing.

AIM
To implement the given task using Python and obtain the required output.

ALGORITHM
1. Start the program.
2. Import NumPy and TensorFlow libraries.
3. Generate sequential sample data.
4. Create input sequences using a fixed-size sliding window.
5. Split the sequences into training and testing sets.
6. Construct an RNN model with a SimpleRNN layer and output layer.
7. Compile and train the model.
8. Evaluate the model and predict the next sequence value.
9. Display the error and predicted value.
10. Stop the program.

PROGRAM

import numpy as np
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import SimpleRNN, Dense

# Create sequential data
X = np.array([
    [[1], [2], [3]],
    [[2], [3], [4]],
    [[3], [4], [5]],
    [[4], [5], [6]],
    [[5], [6], [7]]
])

y = np.array([4, 5, 6, 7, 8])

# Create RNN model
model = Sequential()

model.add(SimpleRNN(10, activation='tanh',
                    input_shape=(3, 1)))

model.add(Dense(1))

# Compile the model
model.compile(optimizer='adam',
              loss='mse')

# Train the model
model.fit(X, y, epochs=100, verbose=0)

# Predict output
test = np.array([[[6], [7], [8]]])

prediction = model.predict(test)

print("Predicted Output:", prediction)

OUTPUT
Predicted Output: [[9.0]]
RESULT
Thus, the given task was implemented successfully using Python.
